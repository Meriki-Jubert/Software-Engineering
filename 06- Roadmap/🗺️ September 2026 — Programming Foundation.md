# 🤖 AI Rules

AI is a **teacher, reviewer, debugger, and research assistant**, not my replacement.

### Before asking AI for help:

1. Understand the problem.
    
2. Attempt a solution myself.
    
3. Debug it myself.
    
4. Explain what I think is happening.
    
5. Ask for a hint before asking for a solution.
    

### I should NOT ask AI to:

- Write an entire project
    
- Solve an exercise immediately
    
- Rewrite code I haven't attempted
    
- Fix an entire application without explaining the problem
    

### I CAN ask AI to:

- Explain a concept
    
- Give me a hint
    
- Explain an error
    
- Review my solution
    
- Point out weaknesses
    
- Suggest what I should learn next
    
- Quiz me
    
- Explain documentation
    

> **Goal:** Become capable enough to judge AI's code instead of blindly depending on it.

# 📊 Mastery Levels

A topic is not considered "learned" simply because I watched a tutorial.

### Level 0 — Unknown

I have never encountered the concept.

### Level 1 — Familiar

I recognize it and understand the basic idea.

### Level 2 — Guided

I can use it with documentation or guidance.

### Level 3 — Independent

I can implement it without significant help.

### Level 4 — Strong

I can debug it, explain it, and recognize when to use it.

### Level 5 — Engineering

I can make design decisions involving it and explain the trade-offs.
