
`Goal: Become an independent software engineer who can take a real-world problem, design a solution, build it, debug it, deploy it, and maintain it without depending on AI to think for me.`


---

### 🗺️ How to Use This Roadmap

This is a directional map, not a prison. I do not need to complete every checkbox before building something. The roadmap is divided into phases. Each phase builds abilities that will be useful in the next.

### My learning principle

`Understand → Practice → Build → Break → Debug → Explain → Repeat`

  

### AI principle
AI is a teacher, reviewer, debugger, and research assistant, not my replacement.
Before asking AI for help:

1. Understand the problem.

2. Attempt a solution myself.

3. Debug it myself.

4. Explain what I think is happening.

5. Ask for a hint before asking for a solution.

My goal is not to avoid AI forever. My goal is to become capable enough to judge AI's work instead of blindly depending on it.

## 📊 SKILL LEVELS

  I will not consider a topic "learned" merely because I watched a tutorial.

- `Level 0 — Never encountered it`, I don't understand the concept.

- `Level 1 — Familiar`, I recognize it and can explain the basic idea.

- `Level 2 — Guided`, I can use it with documentation or guidance.

- `Level 3 — Independent`, I can implement it without significant help.

- `Level 4 — Strong`, I can debug it, explain trade-offs, and teach the concept.

- `Level 5 — Engineering`, I can make architectural decisions involving it in real systems.
